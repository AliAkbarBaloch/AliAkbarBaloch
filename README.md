# Ali Akbar

**Software Engineer — Distributed Systems & AI Engineering**

Software Engineer at Ververica (the original creators of Apache Flink), researching GraalVM Native Image compilation for Flink — reducing startup latency and memory footprint for cloud-native stream processing. Pursuing an MSc in AI Engineering at the University of Passau. Background in fintech and payments engineering: reduced latency by 30% in a C++ trading engine and built fraud-detection pipelines processing 10M+ transactions/day.

📍 Based in Germany · Open to Software Engineering, AI Engineering, and Backend Engineering roles

## Selected Engineering Work

### [AI Object Counting Platform](https://github.com/AliAkbarBaloch/AI-Object-Counting-Platform)

A configurable object-counting service (Segment Anything + ResNet-50 few-shot classification) with a three-stage misuse-resistant safety gate, a Vision Transformer safety classifier trained through a GPU-backed GitLab CI pipeline, and ~20 Prometheus/Grafana metrics for pipeline observability.

`Python` `Flask` `PyTorch` `MongoDB` `Prometheus / Grafana` `GitLab CI`

### [HALO — Human-Agent Loop Orchestrator](https://github.com/AliAkbarBaloch/Human-Agent-Collaboration)

A supervised multi-agent task execution platform extending Microsoft's Magentic-UI architecture with an adaptive human-oversight framework, evaluated across a 22-scenario benchmark as a research seminar project.

`Python` `AutoGen` `TypeScript / React` `Docker`

### [Deutsch Buddy](https://github.com/AliAkbarBaloch/Student-Assistant-Deutsch-Sprache)

A German conversation-practice agent with streaming text chat, real-time WebRTC voice calls, and pronunciation scoring, with every reply's vocabulary constrained to the learner's CEFR level via a 6,377-entry sampling system.

`Python` `FastAPI` `React` `TypeScript` `LiveKit`

### [School Praktikum Planning System](https://github.com/AliAkbarBaloch/School-Praktikum-Planning-System)

A rule-based allocation planner matching practicum teachers to placement demand across subject, zone, and workload constraints, with a review/adjustment UI, JWT-secured REST API, and a 77-file automated test suite — built by a five-person team at the University of Passau.

`Java` `Spring Boot` `React` `TypeScript` `Docker`

### [Time Tracker App](https://github.com/AliAkbarBaloch/Time-Tracker-App)

A full-stack time-tracking application with JWT auth, service-layer-enforced authorization, nested shareable projects, and a CI pipeline gated on ≥90% backend/frontend coverage plus 31 Playwright end-to-end specs.

`Java` `Spring Boot` `Spring Security` `React` `Playwright`

### [E-Commerce Product Management System](https://github.com/AliAkbarBaloch/E-Commerce_Product_Management_System)

A Spring Boot admin system for product, category, and price-history data with a self-referential category hierarchy and Redis caching infrastructure wired end-to-end and deliberately disabled behind a documented design decision.

`Java` `Spring Boot` `Spring Data JPA` `Redis`
